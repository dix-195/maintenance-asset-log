# سجل الصيانة والمتابعة الدورية

Maintenance & Asset Log — تطبيق Android أصلي باللغة العربية لإدارة الأصول وسجل صيانتها وقطعها. يعمل دون اتصال ويحفظ البيانات على الجهاز.

## التشغيل والبناء

يتطلب المشروع JDK 21 وAndroid SDK Platform 35 وBuild Tools 35.0.0. أقل إصدار لتشغيل التطبيق هو Android 8.0 (API 26).

افتح جذر المشروع في Android Studio واختر JDK 21 لإعداد Gradle. في الطرفية، عيّن `JAVA_HOME` و`ANDROID_HOME` حسب مكان التثبيت، ثم نفّذ:

```bash
./gradlew testDebugUnitTest assembleDebug
```

ملف التثبيت التجريبي في `app/build/outputs/apk/debug/app-debug.apk`. بعد دفع التغييرات إلى GitHub يظهر الملف ضمن **Actions → Android APK → Artifacts** باسم `maintenance-asset-log-debug`.

لتشغيل اختبارات Android، شغّل محاكيًا أو صِل هاتفًا ثم نفّذ `./gradlew connectedDebugAndroidTest`. لإنتاج حزمة Release غير موقعة شغّل `./gradlew assembleRelease`، ثم وقّعها بمفتاح التوزيع الخاص بك قبل تثبيتها أو توزيعها.

## الصيانة والتنبيهات

أضف أصلًا وسجّل عملية صيانة له. يمكنك تحديد دورة بالأشهر أو بالكيلومترات، ويمكن الجمع بين الشرطين. حدّث العداد من شاشة تعديل الأصل لمراجعة الاستحقاق بالكيلومترات. لتسجيل إنجاز دورة تالية، افتح عملية الصيانة واختر «تسجيل إتمام دورة جديدة». تُعرض تكاليف كل عملة على حدة.

تُفعّل التنبيهات من الإعدادات. يفحص WorkManager المواعيد دوريًا وبعد تحديث البيانات. قد يتأخر التنفيذ تبعًا لقيود Android. يفتح الإشعار التفاصيل داخل التطبيق، حيث يمكنك مراجعة البيانات قبل تسجيل دورة جديدة.

## البيانات والنسخ الاحتياطي

تُشفّر قاعدة Room باستخدام SQLCipher وتُحمى عبارتها بمفتاح في Android Keystore. يمكن تفعيل قفل التطبيق باستخدام بيانات اعتماد الجهاز أو البصمة المتوافقة.

تحتوي النسخة الاحتياطية على الأصول والصيانة والقطع والصور المخزنة. يبدأ تنسيق الإصدار الأول بالبايتات `MAL 01`، ثم ملح عشوائي بحجم 16 بايت وـnonce بحجم 12 بايت. يُشتق مفتاح AES-256-GCM باستخدام PBKDF2-HMAC-SHA256 و600,000 دورة. يصادق GCM على الترويسة والمحتوى. لفك النسخة، اختر ملفها وأدخل كلمة المرور ثم راجع عدد السجلات وأكّد الاستعادة. تُستبدل البيانات في معاملة واحدة بعد التحقق من النسخة والعلاقات.
