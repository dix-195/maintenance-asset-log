# ميزان | MIZAN

كل تفاصيلك في توازن. تطبيق Android يعمل دون اتصال لإدارة مصروفات السيارة والمنزل والجوال والاشتراكات وأي أقسام تضيفها.

## الاستخدام

- ابدأ من إحدى بطاقات الرئيسية واختر خدمة جاهزة أو أنشئ خدمة وقسمًا حسب حاجتك. القوالب لا تنشئ مصروفات.
- سجّل العملية كمتوقعة أو مستحقة أو مدفوعة أو ملغاة. تحتسب التقارير المبالغ المدفوعة فقط حسب تاريخ الدفع وعملته، وتضم عمليات الصيانة المكتملة من النسخة السابقة مرة واحدة. تُعرض العملات منفصلة دون تحويل.
- عند حفظ دفعة متكررة، ينشئ ميزان الموعد التالي كالتزام متوقع. يتطلب تسجيل الدفع تأكيدًا منك.
- حدّد ميزانيتك الشهرية من الإعدادات. يظهر تنبيه داخل الرئيسية عند استهلاك 80٪ منها.
- فعّل الإشعارات من الإعدادات. تفحص التذكيرات المواعيد وقراءات العدادات المسجلة في التطبيق، وقد يتأخر تنفيذها حسب قيود Android.
- أرشف القسم لإزالته من الرئيسية مع الاحتفاظ بسجل عملياته وتقاريره.

## البيانات والتحديث

يحتفظ الإصدار 2.0 بمعرّف التطبيق ويُرحّل قاعدة Room المشفّرة من الإصدار 1 تلقائيًا. تبقى المركبات وعمليات الصيانة والقطع السابقة متاحة. تدعم النسخة الاحتياطية المشفّرة الجديدة الأقسام والقوالب والعمليات وتقرأ تنسيق النسخة السابقة. يحمي Android Keystore مفتاح قاعدة البيانات وتُشفّر ملفات النسخ الاحتياطي بـ AES-256-GCM ومفتاح مشتق من كلمة مرور المستخدم باستخدام PBKDF2-HMAC-SHA256 و600,000 دورة.

## البناء والاختبار

يتطلب المشروع JDK 21 ومنصة Android SDK 35 وأدوات بناء 35.0.0. يعمل التطبيق على Android 8.0 فأحدث.

```bash
./gradlew testDebugUnitTest assembleDebug
```

يظهر الملف محليًا في `app/build/outputs/apk/debug/app-debug.apk`. على GitHub افتح **Actions → Android APK** واختر تشغيل الفرع، ثم نزّل **maintenance-asset-log-debug** من قسم **Artifacts**.

لاختبار الترحيل والتنقل على Android، وصّل جهازًا أو شغّل محاكيًا ثم نفّذ `./gradlew connectedDebugAndroidTest`.
